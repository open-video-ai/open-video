# Community

OpenVideo is open-source video generation. The source tree is public — contributions are welcome.

## Where to participate

| Channel | Status |
|---|---|
| **GitHub Issues** | Prefer for bugs, feature requests, and discussion while Discord is not live |
| **Pull requests** | See [`CONTRIBUTING.md`](../CONTRIBUTING.md) for paths (prompts, backends, judges, engines) |
| **Discord / chat** | Not public yet — this page will link a real invite when one exists |
| **Site** | [open-video.ai](https://open-video.ai) |

Do not invent social or Discord URLs. If a link is missing here, it is not live.

## How to contribute

Short paths (details in CONTRIBUTING.md):

- **Prompt recipe** → `library/prompts/` (copy `templates/prompt_recipe.md`)
- **Model backend** → `backends/<model>/`
- **Judge plugin** → `judges/`
- **Engine adapter** → `engines/<engine>/`
- **Style LoRA / reference pack** → `library/`

We integrate working ecosystem tools as plugins when possible — see CONTRIBUTING.md.
